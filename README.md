# Aboden Hero

A clean-room 2D side-scrolling action-platformer prototype inspired by early 1990s console games.

## Included
- Side-scrolling camera
- Run / jump / shoot
- Basic enemies and health
- Mobile touch controls
- Keyboard controls
- Pixel-art rendering
- Replaceable placeholder character

## Controls
Desktop: Arrow keys or A/D, K/Up = Jump, J = Shoot.
Mobile: on-screen buttons.

## Replace the player art
Replace the placeholder texture in `src/main.js` with a spritesheet loaded in `preload()`.
Recommended animation set:
- idle
- run (6–8 frames)
- jump
- fall
- shoot standing
- shoot running
- hurt
- death

## Run
Serve the folder over HTTP. GitHub Pages works well for mobile testing.
